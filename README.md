Full-stack machine learning application for predicting ATP tennis match outcomes. Processes 63,000+ historical matches (2000-2023) through a complete data pipeline built with Pandas and Scikit-learn. Trained a Random Forest classifier achieving 70% accuracy, with features including surface win rate, recent form, head-to-head records, and ATP rankings. Backend powered by FastAPI serving predictions as a REST API, with a React frontend for interactive match input and result visualization. Includes a value betting module that compares model probabilities against bookmaker odds, and a Kelly Criterion calculator for optimal bankroll management.
